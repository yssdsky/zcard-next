# ZCard v1.2.113

发布日期：2026-11-01

## 商品封面与编辑入口

- 商品列表右侧操作列固定显示，电脑和手机无需横向找寻「编辑」。点击商品封面或「添加封面」可直接进入「图片与详情」，补充或更换图片后可在当前步骤保存。
- 已有商品直接更新，保留原商品及分类，无需重新创建。锁定商品和无编辑权限账号继续遵守原有操作限制。
- 修复清空封面、全部详情图集后保存仍保留旧图片的问题；手动修改上游商品的封面或介绍后保留本地内容保护。
- 动态报价的服务商品可正常编辑封面、介绍及推荐等展示内容，不再被普通商品的固定售价和交付字段拦截。

## 首页推荐展示与状态保护

- 内置商城首页新增独立「推荐商品」区，默认展示最多 8 件可见推荐商品，并可查看全部；进入搜索或分类列表后保持原有筛选和分页行为。
- 修复商品列表快捷修改售价或成本后，首页推荐被意外取消的问题。
- 修复快捷修改价格或推荐状态时，商品介绍被意外清空的问题。未提交的封面、介绍和推荐状态保持原值；明确取消推荐或清空内容时正常生效。
- 推荐商品继续遵守上架状态、分类隐藏及站点可见范围；分类内置顶与推荐保持独立。

## 动态报价服务商品

- 支持通过具备相应能力的 ZCard 货源接入服务商品，按上游购买规则填写参数、确认报价并使用会员余额付款。
- 订单展示服务进度及已确认退款，按服务能力提供取消或补量申请；购买重试沿用原请求，供货结果未明确时保留待确认状态。
- 实际可用服务、购买规则、取消、补量及退款结果由绑定货源支持情况决定。

## 验证范围

后端全量测试、go vet、真实隔离 MySQL / PostgreSQL 集成测试、前后台类型检查与生产构建、翻译检查和 fullstack 嵌入资源测试均已通过。桌面及手机浏览器回归覆盖补封面、保存失败保留输入、图片清空、权限与锁定、推荐状态保留、默认首页推荐展示、分类/搜索/分页隔离、空推荐筛选与迟到响应隔离。

测试使用合成商品、账号及本地模拟接口；客户站点和真实供货交易需在升级后分别验收。

## 升级说明

请先备份数据库、配置和上传文件，保留原加密密钥，更新完整发行包并重启服务端，同时刷新后台和内置商城。

从 v1.2.112 升级会执行随动态报价服务功能附带的 SQLite、MySQL、PostgreSQL 增量迁移。商品图片和推荐修复本身无需新增表或重新创建商品、分类。独立安装的第三方商城主题需另行更新，主程序发行包不会替换第三方主题文件。

频道公告由用户手动发送。版本发布不代表客户生产站点已自动升级。

版本详情与下载：https://github.com/NovaWorks/zcard-next/releases/tag/v1.2.113
